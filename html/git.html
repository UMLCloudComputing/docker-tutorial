Git Tutorial

Git is a version control system that tracks changes to your files over time, letting you save snapshots of your work and go back to them whenever you need.

Install Git

Make sure you have Git installed. To install on Debian/Ubuntu, run:

sudo apt install git

To make sure Git is installed, run:

git --version

Set your default branch name to main (only needs to be done once per machine):

git config --global init.defaultBranch main

Create the repository

Create a new repository on GitHub, then clone it down to your machine:

git clone https://github.com/USER-NAME/REPOSITORY-NAME.git
cd REPOSITORY-NAME

Confirm the clone worked and check which remote it's connected to:

git remote -v

Use the Git workflow

Create a file and see how Git tracks it:

touch hello_world.txt
git status

Stage the file, preparing it for a commit:

git add hello_world.txt
git status

Commit the staged file with a message describing the snapshot:

git commit -m "Add hello_world.txt"

Modify a file or two

Edit an existing file, then check its status:

git status

Stage just that file:

git add filename.txt

Or stage everything that's changed in the current directory (and below) at once:

git add .

Commit the changes:

git commit -m "Describe what you changed"

Push your work to GitHub

git push origin main
git status

Refresh your repository page on GitHub — your latest commits should now show up there.

Cheatsheet

  • git clone https://github.com/USER-NAME/REPOSITORY-NAME.git
  • git push / git push origin main
  • git add .
  • git commit -m "message describing changes"

Working with Remotes (GitHub)

git remote add origin https://github.com/user/repo.git
git push origin main
git pull origin main
git clone https://github.com/user/repo.git
